메뉴 및 권한

서비스 구조와 사용구분별 접근 범위를 확인합니다. 연결 화면은 구조를 보여 주며, 개별 버튼의 처리 권한을 확정하지 않습니다.

이 문서에서 관리하는 것

여러 화면에 영향을 주는 처리 기준은 공통 정책, 특정 화면만의 차이는 화면별 정책으로 구분합니다. 입력 항목·알럿·버튼별 상세 동작은 해당 화면설계서 및 Description에서 관리합니다.

O: 메뉴 허용 · △: 조건부 허용 · X: 미허용. 업무 처리 권한은 CP-01에서 함께 확인합니다.

사용 종료한 FAQ·자료실·수출상담일지 엑셀 일괄 업로드는 현행 메뉴에서 제외합니다. 기획정책 문서는 화면 코드·Description이 없는 별도 검토 페이지입니다.

공통 정책

한 기준이 여러 화면의 동작을 바꾸는 경우 여기에 한 번만 정의합니다. 정책을 변경할 때 영향 범위와 연결된 화면별 예외를 함께 확인합니다.

목업 확인 현재 구현에서 확인한 기준 · 문서 기준 기존 기획문서 기준 · 검토 필요 최종 합의 전

근거 자료 인덱스 · 기준 스냅샷 확인

코드·문서의 위치를 추적하기 위한 참고 정보입니다. 각 화면의 상세 기능 설명을 이곳에 복제하지 않습니다.

근거 ID자료 및 위치참조 기준
문서 관리 기준과 작성 범위
  • 공통 처리 기준 변경은 공통 정책에서, 특정 화면의 예외 변경은 화면별 정책에서 관리합니다.
  • 입력 필드·알럿 문구·버튼별 상세 동작은 기존 화면설계서 및 Description에서 관리합니다.
  • 미확정 사항이 결정되면 연결된 공통 정책·화면별 예외·실제 화면 명세를 함께 갱신합니다.
  • 이번 v0.2는 기존 초안의 구성 재정리이며, 미확정 정책을 새로 확정한 개정이 아닙니다.

화면별 정책

공통 정책을 반복하지 않고, 해당 화면에만 적용되는 예외·추가 조건과 공통 정책 연결만 관리합니다.

화면설계서와의 경계

화면의 모든 필드나 버튼을 이 문서에 다시 열거하지 않습니다. 위 예외 외의 입력 방식·검증 문구·개별 처리 순서는 해당 화면의 Description을 기준으로 확인합니다.

미확정 사항

현재 자료 간 차이와 추가 결정이 필요한 항목입니다. 연결된 공통 정책과 화면별 예외를 확인한 뒤 결정하며, 합의 전에는 확정 기준으로 사용하지 않습니다.

P1: 개발 전달 전 우선 합의 · P2: 상세화 또는 범위 보완. 확정일·결정자는 합의 후 기록합니다.
