## 읽기와 반영

- 배포된 사용자 제공 원본 XLSX를 연결한다. 국가·언어 참고 목록과 원본 코드·대소문자를 유지한다.
- 등록정보 시트의 현재 열 이름·순서를 검사하며 [예시] 행·빈 행·참고 시트는 등록하지 않는다. 수식은 실제 값으로 바꿔 입력하도록 안내한다.
- 생년월일 실제 날짜, 국가/언어 원본 코드, 언어 중복, 연락처 7~15자리(+·공백·하이픈·괄호 허용), 입력한 이메일 형식을 검사한다.
- 회원은 이름+생년월일, 담당자는 기존/파일 내 ID 중복을 검사한다. 담당자 사용여부는 Y/N 필수다.
- 현행 사이트는 입력 오류 1건 이상이면 전체 미반영한다. 결과 표·별도 반영 버튼 없이 성공/오류 건수·사유를 알럿으로 안내한다. 이 기준과 과거 부분 반영 요청의 차이는 [Q01](확인필요사항.md#q01-엑셀-오류-반영-단위의-불일치)에서 관리한다.
- 구조·읽기·입력 오류 시 팝업과 입력을 유지하고 재업로드한다. 화면/행사/파일이 바뀐 뒤 끝난 이전 검증은 적용하지 않는다.
- 성공 반영의 참가·계정 처리는 [회원·행사·계정](회원_행사_계정.md)을 따른다. 업로드 행사연도와 조회 화면의 과거 연도를 혼용하지 않는다.

## 다운로드

| 구분 | 파일명 |
| --- | --- |
| 전체 목록 | G-FAIR_행사연도_대상구분_YYYYMMDD.xlsx |
| 선택 목록 | G-FAIR_행사연도_대상구분_선택_YYYYMMDD.xlsx |
| 선택 QR 묶음 | G-FAIR_행사연도_대상구분_선택QR코드.zip |
| 전체 QR 묶음 | G-FAIR_행사연도_대상구분_전체QR코드.zip |
| 개별·ZIP 내부 계정 QR | 이름_아이디_qr코드.png |
| 해외바이어 QR | 이름_바이어코드_qr코드.png |

- 날짜는 다운로드 시점의 한국 시간, 행사연도는 조회 중인 행사다. 파일명에서 대상구분 공백을 제거하고 금지 문자는 밑줄로 바꾼다.
- 위 4종 등록양식은 원본 고정 파일명을 사용하며 일반 파일명 규칙의 예외다.
- 선택 다운로드는 체크 대상만, 전체 QR은 현재 행사 전체 참가 대상이며 검색·현재 페이지로 제한하지 않는다. ZIP에는 실제 PNG를 넣는다.
- QR PNG 하단 여백에는 파일명에서 `_QR코드` 접미어를 제외한 문구를 표시한다. 다운로드 파일명은 유지하고 QR·흰 여백을 침범하지 않도록 긴 이름은 줄바꿈한다.
- 실제 열 구성은 현재 화면의 내려받기 코드·Description과 함께 확인한다. 해외바이어 ID/PW 열을 다시 추가하지 않는다.
