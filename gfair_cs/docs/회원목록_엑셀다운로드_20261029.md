## COM-07

이름 · 소속 · 연락처 · 이메일 · 아이디 · 비밀번호 · 사용여부

- 현재 검색 결과 전체를 페이지 구분 없이 다운로드하며 기존 역할·용역사·행사 조회 범위를 유지한다.
- 참가연도는 전체 이력을 유지하고 올해참가여부는 목록의 참가/미참가와 동일하다.
- 연락처·이메일·메모는 상세 화면에서 저장하거나 엑셀로 반영한 최신 값을 사용한다.
- 국가·언어는 기준코드의 이름(코드)로 표시한다. 담당자 비밀번호는 마스킹하지 않은 현재 발급값을 포함한다.
- 기존 다운로드 완료·생성 실패 안내는 유지한다.
