# 참가자 고유식별코드 및 임시계정 정책

확정일: 2026-10-21 / 변경일: 2026-10-28 (한국 시간)

## 1. 참가자 고유식별코드

참가자 식별·연도별 참가이력·매칭·QR 연결에 사용한다. 로그인 ID와 구분한다.

| 대상 | 규칙 | 예시 |
| --- | --- | --- |
| 국내 바이어 | K + 최초 등록 행사연도 4자리 + 일련번호 4자리 | K20270001 |
| 해외 바이어 | F + 최초 등록 행사연도 4자리 + 일련번호 4자리 | F20270001 |
| 통역원 | I + 최초 등록 행사연도 4자리 + 일련번호 4자리 | I20270001 |

일련번호는 0001부터 네 자리로 표현한다. 동일 참가자의 여러 해 이력은 고유코드로 연결한다.

## 2. 로그인 계정 적용 대상

| 대상 | 로그인 ID | 임시 PW |
| --- | --- | --- |
| 해외 바이어 | 발급하지 않음 | 발급하지 않음 |
| 국내 바이어 | GK + 행사연도 뒤 2자리 + 일련번호 4자리 | 자동 발급 |
| 통역원 | GI + 행사연도 뒤 2자리 + 일련번호 4자리 | 자동 발급 |
| 운영용역사 대표·하위 담당자 | 관리자가 직접 지정 | 자동 발급 |

해외바이어는 시스템 로그인 계정이 없다. 등록·엑셀 업로드·행사 참가 처리에서 ID/PW를 생성·입력·발급·재발급하지 않는다. 기존 목업의 GF 형식 로그인 계정은 폐기한다.
해외바이어 기본정보, 참가연도·초청기관 이력, 통역원 매칭, 방한 QR 스캔 기능은 고유코드를 기준으로 유지한다.

## 3. 임시비밀번호

운영용역사(대표·하위 담당자)·국내 바이어·통역원에만 공통 적용한다.
영문 대문자 1자 + 숫자 6자리, 총 7자 무작위 발급이다. 예: A327851.
정규식: ^[A-Z][0-9]{6}$

- 단건 등록·엑셀 일괄등록·계정 발급·예시 데이터에 동일 적용한다.
- 연도·ID·순번을 조합한 Demo 값 또는 별도 16자리 생성 규칙을 사용하지 않는다.
- 조회·보기/숨기기·상세 이동만으로 발급값을 재생성하지 않는다.
- 기본 마스킹하며 실제 개인정보·비밀번호는 목업에 넣지 않는다.
- 관리자 직접 설정 비밀번호의 별도 정책은 유지한다.

## 4. 해외바이어 QR·다운로드

- QR은 로그인 계정 없이 행사연도 + 해외바이어 고유코드로 연결한다.
- 목록·상세·참가이력·엑셀에 해외바이어 로그인 ID/PW·계정 발급 상태를 표시하지 않는다.
- 해외바이어 개별 PNG와 ZIP 내부 이미지: 이름_바이어코드_qr코드.png.
- 예: James Whitmore_F20260001_qr코드.png.
- 다른 계정 대상의 PNG는 기존 이름_아이디_qr코드.png를 유지한다.
- ZIP·엑셀 파일명과 QR 이미지 하단 실제 파일명 표시는 공통 규칙을 따른다.
- 바이어명·고유코드·생년월일은 계속 관리한다. 이메일 주소의 아이디는 로그인 ID와 무관하다.

## 5. 미확정 세부 사항

일련번호 중복 방지 범위·소진 시 처리·삭제 번호 재사용 및 계정 대상의 재발급·전달 절차는 별도 협의한다.
실제 인증·계정·QR 저장과 전달은 서버 연동 단계에서 구현한다.
