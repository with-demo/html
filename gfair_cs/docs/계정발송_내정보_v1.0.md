# 메뉴권한·계정발송·내정보

2026-10-29 (한국 시간), with

- 메뉴권한의 만족도설문 관리는 설문관리·응답관리 대신 한 개의 체크 항목으로 표시한다. 관리자 그룹만 선택할 수 있고 다른 그룹은 비활성·미선택으로 표시한다. 실제 LNB의 설문관리·응답관리 구분은 유지한다.
- BAS-15·COM-07 목록 상단에는 선택 계정발송·일괄 계정발송을 제공한다. 사용자 지정에 따른 목록 상단 도구 기능이다.
- 행 체크박스는 개별 선택, 헤더 체크박스는 현재 페이지의 보이는 행 전체 선택이다. 페이지를 이동해도 선택은 유지하고 검색 조건·역할·행사·소속이 바뀌면 초기화한다.
- 선택 발송은 현재 조회 결과 중 체크한 대상, 일괄 발송은 현재 조회 결과의 전체 페이지를 대상으로 한다.
- BAS-15는 관리자에게만, COM-07은 소속 운영용역사·조회 행사 담당자 범위에서만 제공한다.
- 발급 ID·PW 및 올바른 연락처가 있는 대상만 포함한다. 유효하지 않은 대상은 발송 대상에서 제외한다.
- 문자 내용: 행사연도 / 사이트 로그인 URL / 발급 아이디 / PW. 사이트 URL은 현재 사이트의 index.html#COM-01이다.
- 선택/일괄 계정발송 클릭 즉시 브라우저 기본 컨펌을 표시한다. 10명까지 전체 이름을, 11명부터 앞 10명의 이름과 외 나머지 인원을 표시한다. 줄바꿈 후 총 N명에게 계정정보를 발송하시겠습니까?로 안내한다.
- 확인 시 발송 직전 대상 계정·연락처를 재검증하고 처리하며, 취소 시 목록과 선택을 유지한다. 문자 내용은 컨펌에서 표시하지 않고 Description에만 안내한다.
- 현재는 검토용 발송 예시다. 실제 SMS 요청·계정 인증정보 전송은 하지 않는다.
