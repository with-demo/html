# BAS-19 운영용역사 등록 Description 초안 v0.1

- 작성일: 2026-10-26 (한국 시간)
- 참고: BAS-18 실제 등록 Description
- 범위: 행사연도·구분·담당자 연락처·담당자 이메일·사용여부
- 기업명·담당자 이름은 제외

## 01 행사연도

- 유형: 셀렉트박스
- 기본값: 현재 목업 행사연도(2026)
- 필수: Y
- 선택 옵션: 행사관리(BAS-01)에 등록된 연도 / 내림차순
- 상세 설명: - 운영용역사를 배정할 행사연도를 선택
  - 행사관리 목록에 등록된 연도를 중복 없이 최신 연도부터 표시
  - 현재 목업 행사연도가 목록에 있으면 기본 선택
  - 선택 가능한 연도가 없거나 연도를 선택하지 않으면 등록 불가
- 검증: 필수 선택 / 행사관리 등록 연도에 포함되어야 함
- 데이터 출처: BAS-01 행사관리 연도
- 오류 안내: 필수 항목을 확인해 주세요.

## 02 구분

- 유형: 라디오박스
- 기본값: 구매상담
- 필수: Y
- 선택 옵션: 구매상담 / 수출상담
- 상세 설명: - 운영용역사가 담당할 상담 구분을 선택
  - 구매상담 / 수출상담 중 한 개만 선택
  - 기본값은 구매상담이며 선택값을 해당 행사 배정 정보에 반영
- 검증: 필수 선택 / 구매상담·수출상담 중 한 개
- 오류 안내: 필수 항목을 확인해 주세요.

## 03 담당자 연락처

- 유형: 인풋
- 기본값: 앞자리 010 / 가운데·마지막 빈 값
- 필수: Y
- 선택 옵션: 010 / 011 / 016 / 017 / 018 / 019 / 02 / 031 / 032 / 033 / 041 / 042 / 043 / 044 / 051 / 052 / 053 / 054 / 055 / 061 / 062 / 063 / 064 / 070
- 상세 설명: - 등록 화면에서 담당자 연락처를 직접 입력
  - 앞자리 선택 + 가운데 숫자 3~4자리 + 마지막 숫자 4자리로 입력
  - 가운데·마지막 입력란은 숫자만 입력하며 최대 4자리로 제한
  - 각 입력란은 필수이며 번호를 하이픈(-)으로 연결해 등록
- 입력 형식: 숫자
- 입력 제한: 가운데·마지막 입력란 각각 최대 4자리
- 검증: 앞자리 필수 선택 / 가운데 숫자 3~4자리 / 마지막 숫자 4자리
- 오류 안내: 미입력·자리수 오류 시 브라우저 기본 입력 검증 안내
- 데이터 출처: 운영용역사 등록 화면 직접 입력

## 04 담당자 이메일

- 유형: 인풋
- 기본값: 아이디·도메인 빈 값 / 직접입력
- 필수: N
- 선택 옵션: naver.com / gmail.com / daum.net / hanmail.net / nate.com / outlook.com / hotmail.com / 직접입력
- 상세 설명: - 등록 화면에서 담당자 이메일을 선택 입력하며 미입력 시 빈 값으로 저장
  - 아이디와 도메인을 나누어 입력하며 @를 사이에 표시
  - 도메인은 기본 메일 주소 선택 또는 직접입력
  - 도메인 선택 시 해당 값을 반영하고 읽기 전용으로 전환
  - 직접입력 선택 시 현재 도메인 값을 유지하며 편집 가능
  - 입력한 경우 아이디·도메인 누락 및 이메일 형식 검증
- 입력 형식: 이메일
- 입력 제한: 아이디 최대 64자 / 도메인 최대 253자
- 검증: 선택 입력 / 입력한 경우 아이디·도메인 누락 및 이메일 형식 검증
- 오류 안내: 이메일 아이디와 도메인을 올바르게 입력해 주세요.
- 데이터 출처: 운영용역사 등록 화면 직접 입력
- 정책: - 선택 입력 항목

## 05 사용여부

- 유형: 라디오박스
- 기본값: 사용
- 필수: Y
- 선택 옵션: 사용 / 미사용
- 상세 설명: - 운영용역사 사용여부를 사용 / 미사용 라디오 버튼으로 선택
  - 기본값은 사용이며 두 값 중 한 개만 선택
  - 기본정보의 마지막 행에 전체 너비로 표시
  - 등록 시 선택값을 운영용역사 정보에 반영
- 검증: 필수 선택 / 사용·미사용 중 한 개
- 오류 안내: 필수 항목을 확인해 주세요.
