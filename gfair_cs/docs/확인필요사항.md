우선순위: P1 · 근거: S14

## Q01 행사정보 회원 업로드의 전체 미반영 기준 (확정)

상태: 확정 · 우선순위: P1 · 근거: S09, S10

- 현재 확인: 등록·엑셀 일괄 업로드는 PRE-01·EVT-01·EVT-02 행사정보에서만 제공한다. 해외·국내바이어·통역원 파일에 오류행이 1건이라도 있으면 파일 전체를 미반영한다. BAS-03·05·07은 원천 회원 데이터·양식 모듈 구분이며 현재 업로드 메뉴 위치가 아니다.
- 다음 결정/처리: 오류 수정 후 파일 전체를 재업로드한다. 오류 파일은 신규 회원·기존 정보·행사 참가·계정·QR에 반영하지 않는다. 다른 업로드 화면은 각 화면의 기존 기준을 따른다.

## Q04 방한 전이의 운영 검증과 저장 Description 불일치

우선순위: P1 · 근거: S15

- 현재 확인: 미입국 최초 상태, 상담일지 시작·종료 연동, 입국일 기준 일차, 최신순 이력과 일시·사유 정정·취소가 구현됐다. PRE-02 저장 Description에는 호텔 출발(화면은 전시장 출발), 수정 버튼은 상태 변경(화면은 일시·사유 수정) 문구가 남아 있다.
- 다음 결정/처리: 화면의 확정 동작은 유지한다. 해당 Description은 별도 화면/명세 정리에서 사용자의 편집을 보존하며 맞춘다. 역순·건너뛰기·재입장 허용과 통계 포함 규칙은 운영 검증 대상으로 유지한다.

## Q05 설문 1회 제출의 서버 판정

## Q10 표준상담일지의 부분 반영과 유형별 차이

우선순위: P1 · 근거: S11, S12
