# BAS-04 연락처 국가번호 선택 (2026-10-29)

- 국가 목록: 사용자 제공 기준자료의 250개 국가 이름·코드·순서를 유지.
- 표시: 국가명(국가코드) +전화국가번호. 빈 값은 국가번호 선택으로 표시.
- 전화 국가번호 매핑: https://unpkg.com/libphonenumber-js@1.13.15/metadata.min.json (국가 목록을 대체하지 않음). 매핑 데이터만 사용.
- 매핑 미확인 7개 항목은 목록에 유지하고 국가번호 정보 없음으로 선택 불가 표시: 남극(AQ), 부베 섬(BV), 프랑스 남부 지방(TF), 허드 맥도널드 제도(HM), 핏케언 제도(PN), 사우스조지아 사우스샌드위치 제도(GS), 미국령 군소 제도(UM).
- 동일 국가번호를 공유하는 국가도 각각 선택하고, 선택 국가코드를 별도 보존. 바이어국가와 연락처 국가는 서로 독립.
- 기존 번호는 국가번호를 기준으로 선택값 복원. 저장된 국가 선택을 우선하고, 없으면 바이어국가가 번호와 일치할 때만 사용. 일치하는 국가가 없는 기존 번호는 기존 국가번호로 유지하여 숫자 손실 방지.
- 모두 빈 값 허용. 일부 입력 시 국가 선택 및 전화번호 세 칸을 모두 입력. 각 전화번호는 숫자 1~7자리, 전체 7~15자리.
- +국가번호-앞자리-가운데-끝자리로 저장. 국가 셀렉트 변경 시 숫자 세 칸은 유지. 엑셀 재반영 시 새 번호에서 선택값 재구성.
- 기존 알럿/컨펌 정의 초기화 상태를 유지하며 관련 검증은 연락처 Description 안에 명시.
