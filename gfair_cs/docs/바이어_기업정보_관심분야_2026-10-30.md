# 바이어 기업정보·관심분야 상세 초안

2026-10-30 한국 시간. 사용자 제공 최신 해외·국내 엑셀의 원본 열·필수 여부를 기준으로 변경.

- 기본정보: 이름·생년월일·국가(해외)·연락처·이메일·초청기관.
- 기업정보: 기업명·기업코드(해외)·직위, 비즈니스 유형, 유통채널(국내), 홈페이지·주소·회사소개.
- 관심분야: 1차·2차 셀렉트. 1차 변경 시 2차를 비우고 해당 옵션을 다시 표시한다.
- 해외 참가이력: 연도·기업명·기업코드·초청기관. 국내: 연도·기업명·초청기관. 과거 이력은 현재 기업정보 변경으로 덮어쓰지 않는다.
- 추가 입력값은 엑셀 재업로드로 지우지 않는다. 기존 목록 열·검색·선택 기능은 변경하지 않는다.
- 관심분야 1차 초안: 리빙·식품·뷰티·기타. 뷰티 2차는 사용자 캡처 8개 항목, 그 외는 기존 목업의 품목 분류를 사용한 임시 초안이며 최종 목록 확인 대상. 산업군 기준코드와 구분한다.

- 상세의 참여여부 입력과 메모 영역을 제거한다. 참여 상태는 기존 목록의 미참여 처리에서 관리한다.
- 필수 표시는 공통 required-asterisk 클래스의 빨간색(#c62828)을 사용한다.
- 관심분야 최종 분류는 사용자 별도 목록 전달 대기 상태다.
