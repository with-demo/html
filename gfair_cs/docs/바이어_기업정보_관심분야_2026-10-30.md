# 바이어 기업정보·관심분야 상세 초안

2026-10-30 한국 시간. 사용자 제공 최신 해외·국내 엑셀의 원본 열·필수 여부를 기준으로 변경.

- 기본정보: 이름·생년월일·국가(해외)·연락처·이메일·초청기관.
- 기업정보: 기업명·기업코드(해외)·직위, 비즈니스 유형, 유통채널(국내), 홈페이지·주소·회사소개.
- 관심분야: 메인·서브 카테고리를 완성하면 다음 빈 행을 자동 추가한다. 여러 관심분야 저장·개별 제거를 제공한다.
- 해외 참가이력: 연도·기업명·기업코드·초청기관. 국내: 연도·기업명·초청기관. 과거 이력은 현재 기업정보 변경으로 덮어쓰지 않는다.
- 추가 입력값은 엑셀 재업로드로 지우지 않는다. 기존 목록 열·검색·선택 기능은 변경하지 않는다.
- 관심분야는 사용자 제공 8개 캡처를 기준으로 미용(Beauty)·패션(Fashion)·식품(Food)·인테리어(Houseware)·주방(Kitchen)·레저(Leisure)·전자기기(Smart)·테크(Tech), 하위 62개 항목을 적용한다. 산업군 기준코드와는 별도다.

- 상세의 참여여부 입력과 메모 영역을 제거한다. 참여 상태는 기존 목록의 미참여 처리에서 관리한다.
- 필수 표시는 공통 required-asterisk 클래스의 빨간색(#c62828)을 사용한다.
- 사용자 전달 카테고리 목록 반영 완료. 같은 메인·서브 조합의 중복 선택은 차단하고, 메인만 선택한 행은 서브 선택 후 저장한다.

## 상세 배치

- 해외 기본정보: 바이어코드 전체 행 → 바이어명/생년월일 → 국가/연락처 → 이메일/초청기관. 초청기관 예시 GBC_바르샤바.
- 국내 기본정보: 바이어코드 전체 행 → 바이어명/생년월일 → 연락처/이메일 → 초청기관 전체 행.
- 해외 기업정보: 기업코드 전체 행(QA123456) → 기업명(ABC market)/직위 → 비즈니스 유형 전체 행.
- 국내 기업정보: 기업명/직위 → 비즈니스 유형 전체 행 → 유통채널 유형 전체 행.
- 홈페이지·주소·기업소개는 각각 전체 행이며 기존 회사소개 명칭은 기업소개로 변경한다.
