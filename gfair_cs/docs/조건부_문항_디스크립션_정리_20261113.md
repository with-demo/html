# 조건부 문항 Description 정리

- 수정일: 2026-11-13 (한국 시간)
- SET-13 02 조건부 문항 안내: 조회 전용 미리보기의 문항·응답 조건 확인 방식으로 정리. 실제 응답 검사·제출·통계 제외 정책을 미리보기의 유효성 검사에서 제거.
- NTC-08 03 조건부 문항: 선행 선택에 따른 활성·비활성, 필수 별표·응답 검사, 답변·부가정보 초기화, 비활성 답변 저장·통계 제외를 구분하여 명시.
- 기능상세는 동작 중심 단답형, 기본정책은 설명형으로 작성. 기존 설명 ID·번호·댓글·기획비고를 보존하고 변경한 문장을 빨간색으로 표시.
- 미리보기의 조회 전용 기능은 변경하지 않음.
