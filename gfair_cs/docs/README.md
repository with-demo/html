## 기준과 변경 방법

- 현재 요청의 명시적 지시를 우선한다. 이 문서는 3a6a96d562940d3b57472cb20d9539bd5b515beb 공개 소스와 저장 Description을 대조한 기준이다.
- 공통·화면별·미확정 정책의 ID와 본문은 「../data/planning-policy.js」의 commonPolicies·screenPolicies·issues 한 곳에서 관리한다. 사이트 기획정책과 이 MD는 같은 데이터를 사용한다.
- 입력 항목·옵션·알럿·핀·댓글은 Description 서버가 원본이다. 예전 초안 MD를 현재 Description 대신 사용하거나 일괄 복원하지 않는다.
- 구글시트는 검토·담당자·결정사항 관리용이다. 사이트·MD·구글시트 사이의 자동 양방향 동기화는 없다. 반영할 때 정책 ID로 대조한다.
- 날짜별 수정 메모와 폐기된 초안은 현행 문서에서 제거했다. 정리 전 원문은 별도 로컬 백업과 Git 이력에 보존한다. outputs·백업·템플릿 폴더를 현행 정책의 근거로 다시 끌어오지 않는다.
- 화면 동작이나 저장 Description이 서로 다르면 임의로 정책을 확정하지 않고 확인필요사항에 기록한다. 문서 정리는 기능 변경이나 미배포 기능의 배포 완료를 뜻하지 않는다.

## 공통 정책 본문 갱신

정책 데이터 수정 후 저장소에서 아래 명령으로 공통·화면별·확인필요 MD를 다시 생성한다. 회원·엑셀·요구사항·작업 규칙 문서는 관련 업무 변경 시 함께 검토한다. 구글시트와 실제 Description은 별도로 읽고 정책 ID·설명 ID로 반영한다.

    node gfair_cs/tools/sync-policy-docs.cjs

- 실행 참조가 없는 과거 반영·참고 JSON 69개를 활성 문서 폴더에서 제외했다. 원문 추출·메뉴 대응표·검수기록 3개는 로컬 참조 폴더에 내용 변경 없이 보존하고, 과거 설명 패치 66개는 별도 백업·Git 이력에 보존한다. [보관 안내](../reference/README.md)를 참고한다. 현재 서버 Description·댓글·핀은 유지한다.
