# BAS-17 기본정보 수정 Description v1.20

- 작업일: 2026-10-26 (한국 시간)

## 기본정보

- 행사연도·구분·기업명·사용여부만 입력·선택 방식으로 수정
- 행사연도는 등록된 행사관리 연도와 현재 배정 연도 중 선택
- 구분은 구매상담 / 수출상담, 사용여부는 사용 / 미사용 중 선택
- 기존 등록값을 초기값으로 표시하며 네 항목 모두 필수
- 기업명 공백, 다른 기업과 이름 중복, 같은 기업의 행사연도·구분 중복을 검사
- 담당자 정보는 별도 조회 영역이며 담당자 이름·연락처·이메일·발급ID·PW는 수정하지 않음
- 행사연도를 변경해도 기존 담당자 연결과 발급 계정값은 유지

## 하단 작업 버튼

- 우측 최하단에 [목록], [수정] 버튼을 한 쌍으로 표시
- 수정은 기본정보 네 항목만 검증·반영하며 상세 화면 유지
- 기업명·사용여부는 동일 기업의 목록·상세에 함께 반영하고 행사연도·구분은 선택한 배정에 반영
- 오류가 있으면 수정 중단 후 입력값 유지
- 담당자 검색·PW 보기 시에도 수정 중 입력값 유지
- 목록 선택 시 저장하지 않고 BAS-15로 이동
- 목업의 현재 탭 예시 데이터에만 반영하며 실제 서버·계정은 변경하지 않음

## 알럿/컨펌

### 운영용역사 기본정보 필수값

- 발생 조건: 기업명이 공백이거나 행사연도·구분·사용여부가 유효하지 않은 상태에서 수정 실행
- 메시지: 필수 항목을 확인해 주세요.
- 처리: 수정을 중단하고 현재 입력값 유지

### 운영용역사 기업명 중복

- 발생 조건: 다른 운영용역사와 같은 기업명으로 수정 실행
- 메시지: 같은 기업명이 이미 등록되어 있습니다.
- 처리: 수정을 중단하고 현재 입력값 유지

### 운영용역사 행사 배정 중복

- 발생 조건: 같은 기업에 동일 행사연도·구분 배정이 이미 있는 상태에서 수정 실행
- 메시지: 같은 행사연도·구분에 이미 등록된 운영용역사입니다.
- 처리: 수정을 중단하고 현재 입력값 유지

### 수정 대상 없음

- 발생 조건: 수정 실행 시 현재 기업 또는 행사 배정 정보를 찾을 수 없음
- 메시지: 수정할 운영용역사를 찾을 수 없습니다.
- 처리: 수정을 중단하고 현재 상세 유지

### 운영용역사 기본정보 수정 완료

- 발생 조건: 필수값·기업명 중복·행사 배정 중복 검증 통과 후 수정 실행
- 메시지: 운영용역사 기본정보를 수정했습니다. 현재 탭에만 반영됩니다.
- 처리: 기본정보를 현재 탭 예시 데이터에 반영하고 상세 유지. 목록에도 변경값 반영
