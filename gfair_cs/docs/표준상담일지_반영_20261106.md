## 유지한 기존 범위

- 수출 기업·바이어 자동 연계, 통역원·대리 작성자 구분, 명함 첨부, 추가 상담성과, 해시태그.
- 기존 관리자/용역사/작성자 접근과 승인·반려·재제출 흐름.
- 원본의 독립형 500개 시연기업·데모 ID·JSON 내려받기·별도 디자인은 옮기지 않음.
- 기존 예시 일지의 과거 거래가능성 값을 상담수준 C1~C5로 임의 환산하지 않음.
- 기존 금액을 환산하지 않으며, 구매 기존 원 금액은 폼 표시 시 10,000으로 나눔.

## 저장 계약

`journalSchema=gfair-standard-journal-v1`, `consultDate`, `consultationLevel`, `issueCode`, `followUpYn`, `followUpType`, `contractProgressCount`, `potentialAmountUnestimated`, `companyConfirmedCode`.

기존 `amount`/`contract`는 정규화 금액을 저장한다. 구매는 KRW 원, 수출은 USD. 신규 `consultAmountKrw`/`potentialAmountKrw` 또는 `consultAmountUsd`/`potentialAmountUsd`에 같은 값을 보관한다. 비대상 통화 필드는 null. 임의 환율을 적용하지 않는다.

## 연동 범위

화면 소스 및 관련 Description·알럿/컨펌 정의를 함께 반영한다. 신규 설명에는 초안 작성 안내를 추가하지 않는다. 기존 설명은 ID·댓글·무관한 내용·기획비고를 보존하고 수정된 텍스트 범위에만 변경 색상을 적용한다.
