# BAS-04 연락처 분리 입력

2026-10-29 (한국 시간), v0.36

- 국가번호 / 앞자리 / 가운데 / 끝자리 네 개 텍스트 입력란. 국가번호 앞 +는 고정 표시.
- 모두 빈 값은 허용하며 입력 시 네 칸을 모두 작성. 국가번호는 1~3자리(첫 자리 1~9), 나머지는 각 1~7자리 숫자이며 전체 숫자는 7~15자리. 국내 휴대전화 형식이나 각 4자리로 고정하지 않는다.
- 기존 번호·엑셀 번호는 국가번호를 분리하고 기존 3개 번호 묶음을 보존한다. 구분 없는 번호는 끝 4자리·가운데 최대 4자리를 기준으로 표시하되 숫자는 보존한다. 저장 시 +국가번호-앞자리-가운데-끝자리로 연결한다.
- 국가번호 분리 참고 스냅샷: https://unpkg.com/libphonenumber-js@1.13.15/metadata.min.json (프로젝트 국가 ISO 코드표와 별개, 원본 국가코드는 수정하지 않음).
- BAS-06·BAS-08의 기존 연락처 입력은 유지한다.
