# COM-07 v1.15 · COM-08 v0.6 · 2026-10-26

- BAS-16과 동일한 이름·아이디·소속·사용여부·등록일 열 표시
- 사용여부: 전체/사용/미사용, 키워드 범위: 전체/이름/아이디/소속
- 상단 현재 행사와 본인 회사에 배정된 담당자만 조회
- 이름 선택 시 COM-08에서 해당 담당자 수정, 등록 선택 시 COM-08 신규 등록

- BAS-18 등록 화면과 동일한 이름·아이디·소속·비밀번호·비밀번호 확인·전화번호·휴대전화번호·이메일·사용여부 항목과 배치 사용
- 이름·아이디·비밀번호·비밀번호 확인은 신규 등록 시 필수
- 아이디 중복확인 후 등록, 확인 후 아이디 변경 시 재확인
- 비밀번호는 영문·숫자 포함 8~20자리, 확인값 일치
- 전화번호·휴대전화번호·이메일은 선택 입력, 입력 시 형식 검증
- 기존 담당자는 아이디 조회 전용, 비밀번호는 변경 시에만 입력
- 소속은 선택 입력, 내부 회사·행사 연결은 현재 로그인 운영용역사와 현재 행사에 고정
- 목록은 COM-07 이동, 등록/저장은 현재 탭 예시 데이터에 반영

- 현재 사용여부·키워드 검색 결과 전체를 이름·아이디·소속·사용여부·등록일 XLSX로 다운로드
- 엑셀 일괄업로드 선택 시 COM-07-p01 팝업 표시
- 등록 양식 다운로드 → 파일 선택 → 파일 검증 → 정상 미리보기 → 일괄등록
- 양식 열: 이름/아이디/소속/비밀번호/비밀번호 확인/전화번호/휴대전화번호/이메일/사용여부
- 필수값·기존/파일 내 아이디 중복·비밀번호 규칙/확인·연락처·이메일·사용여부 검증
- 오류가 한 건이라도 있으면 전체 등록 중단, 오류 수정 후 재검증
- 확인 직전 아이디 중복 재검사, 다른 회사나 행사에는 등록하지 않음
- 비밀번호는 목록 다운로드와 검증 미리보기에 표시하지 않음
- 팝업 닫기/화면 이동 시 검증 결과 폐기, 현재 탭에만 반영

BAS-16은 기존 화면을 유지한다.
