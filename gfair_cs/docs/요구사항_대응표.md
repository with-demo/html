운영 보안·접근 통제·암호화·감사 로그 보존 기간·성능·가용성·법령/표준·클라우드·교육·계약 검수는 정적 목업 문서 정리로 완료 처리하지 않는다. 승인안과 배포 상태의 차이는 확인필요사항에서 관리한다.

[원문 추출·과거 검수 참고자료](../reference/README.md)는 로컬에 내용 변경 없이 보존한다. 현행 화면 및 충족 상태와 구분하여 사용한다.

## 현재 반영 내용과 검수 경계

- SFR-006/007: MON-08 리스트·그리드·공통 출석 요약은 구현되어 있으나 실제 QR·서버 출결 집계는 미연동이다.
- SFR-010/011: 행사정보 등록·전체 미반영 업로드·일차별 방한기록·상담 시각 연동·기록취소 이력·통역원 인력구분을 현재 화면 기준으로 정리했다.
- SFR-004/005: 구매·수출 폼의 현재 반영 범위와 승인 표준양식의 남은 차이는 Q10을 따른다.
- ACC-001: 관리자·용역사 상단 알림 링크 제거는 표시 변경이며, 알림센터 접근권한·실제 알림 발송 연동 완료를 뜻하지 않는다.
