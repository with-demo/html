# BAS-17 · v1.23 · 2026-10-26

- 행사연도·구분·기업명·대표연락처·대표이메일·사용여부를 수정
- 행사연도·구분·기업명·사용여부는 필수, 대표담당자명은 조회 전용
- 대표연락처와 대표이메일은 선택 입력이며 빈 값 저장 가능
- 연락처 입력 시 국내 전화번호 형식을, 이메일 입력 시 이메일 형식을 검증
- 기업명·대표담당자명, 대표연락처·대표이메일을 각 한 행에 두 항목씩 배치
- 사용여부는 맨 마지막 단독 행에 전체 너비로 표시
- 저장한 대표연락처·대표이메일은 아래 담당자 정보 대표 행에도 동일하게 반영
- 담당자 검색·PW 보기 시 저장 전 입력값 유지
- 하위 담당자와 발급ID·PW는 수정하지 않으며 행사연도 변경 시 담당자 연결 유지

기획비고: [변경사항 있음 · 2026-10-26] 대표연락처·대표이메일 수정 및 사용여부 마지막 단독 행 배치.
