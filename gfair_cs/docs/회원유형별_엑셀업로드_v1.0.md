# 회원유형별 엑셀 등록양식·검증

2026-10-28 (한국 시간), with

## 해외바이어 (BAS-03)

- 필수: 바이어명, 생년월일(yyyy-mm-dd), 바이어국가(코드)
- 선택: 초청기관, 연락처, 이메일, 메모

## 국내바이어 (BAS-05)

- 필수: 바이어명, 생년월일(yyyy-mm-dd)
- 선택: 소속기업, 초청기관, 연락처, 이메일, 메모

## 통역원 (BAS-07)

- 필수: 통역원명, 생년월일(yyyy-mm-dd), 언어1(코드)
- 선택: 언어2(코드), 언어3(코드), 언어4(코드), 언어5(코드), 연락처, 이메일, 메모

## 담당자 (COM-07)

- 필수: 아이디, 이름, 연락처
- 선택: 소속, 이메일, 사용여부(Y/N)

## 공통

- 등록정보 시트만 읽고 회색 기울임 [예시] 행·코드값 참고 시트는 등록하지 않는다.
- 해외바이어는 국가 250개, 통역원은 언어 104개 원본 이름·코드를 참고 시트로 제공한다.
- 생년월일은 yyyy-mm-dd 실제 날짜, 연락처는 숫자 7~15자리(+·공백·하이픈·괄호 허용), 이메일은 입력 시 검사한다.
- 회원은 파일 내 이름+생년월일 중복, 담당자는 기존/파일 내 아이디 중복을 검사한다.
- 참가연도는 선택한 행사연도를 적용하고 용역사 소속은 로그인 정보를 사용한다.
- 담당자 사용여부는 Y/N, 미입력은 Y. 임시 PW는 기존 7자리 무작위 규칙으로 자동 발급한다.
- BAS-05-p01의 결과 표 미노출·오류 건수/사유 알림은 유지한다. 나머지 화면의 결과 표 방식은 유지한다.
- 입력한 선택 항목도 상세 프로필에 함께 저장·조회한다. 해외바이어 로그인 ID/PW는 발급하지 않는다.
