## 공통

- 등록정보 시트만 읽고 회색 기울임 [예시] 행·코드값 참고 시트는 등록하지 않는다.

- 생년월일은 yyyy-mm-dd 실제 날짜, 연락처는 숫자 7~15자리(+·공백·하이픈·괄호 허용), 이메일은 입력 시 검사한다. 해외 바이어 연락처는 +국가번호를 포함한다.
- 회원은 파일 내 이름+생년월일 중복, 담당자는 기존/파일 내 아이디 중복을 검사한다.
- 참가연도는 행사관리의 진행 상태인 행사연도(현재 목업: 2026년)를 적용하고 용역사 소속은 로그인 정보를 사용한다.
- 담당자 사용여부는 Y/N 필수, 미입력은 오류. 임시 PW는 기존 7자리 무작위 규칙으로 자동 발급한다.
- 4개 회원유형 모두 결과 표와 별도 반영 버튼을 표시하지 않는다. 모든 행이 정상일 때만 전체를 즉시 반영한다. 입력 오류가 한 건이라도 있으면 정상 행을 포함해 전체 미반영하며, 오류 행 수와 사유별 오류 행 건수를 알럿으로 안내한다.
- 파일 구조·읽기 오류도 전체 미반영한다. 입력 오류·양식 오류 모두 팝업을 유지하며 전체 파일을 수정하여 재업로드한다. 전체 정상일 때만 팝업을 닫고 목록을 갱신한다.
- 기존 ID와의 중복은 담당자 검증 완료 시점에 다시 확인한다. 파일 변경·화면 이동·행사 변경 중 완료된 이전 검증은 반영하지 않는다.
- 입력한 선택 항목도 상세 프로필에 함께 저장·조회한다. 해외바이어 로그인 ID/PW는 발급하지 않는다.
