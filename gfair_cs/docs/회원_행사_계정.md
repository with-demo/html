# 회원·행사·계정

기준일: 2026-11-11 (한국 시간) · 정리본 v1.1

## 참가와 제외

- 기본정보관리 BAS-03·05·07과 행사정보 PRE-01·EVT-01·EVT-02는 같은 회원을 행사연도별 참가 상태로 연결한다.
- 단건 등록 또는 엑셀 반영이 완료되면 별도 최종확정 없이 행사 목록에 즉시 표시한다. 최종확정 버튼·확정 후 명단 잠금은 사용하지 않는다.
- 해외바이어는 QR만, 국내바이어·통역원은 해당 행사 ID/PW와 QR을 자동 발급한다.
- 제외하면 해당 행사 목록에서 숨기고 발급 ID·QR은 미사용 처리한다. 기본정보는 미참여로 표시하고 참가연도 표시에서 해당 연도를 제외한다.
- 같은 행사에 다시 추가하면 기존 ID/PW·QR을 재활성화한다. 원본·고유코드·발급 정보·다른 연도의 이력을 삭제하거나 새 ID로 바꾸지 않는다.
- 행사에 추가된 회원만 반영한다. 파일에 없는 기존 회원은 자동 제외하지 않는다. 새 행사연도는 미참여로 시작한다.
- 참가이력의 삭제는 현재 행사 행에만 제공하며 물리 삭제가 아닌 숨김·미참여다. 과거 행사 행에는 삭제 버튼을 표시하지 않는다.
- 행사 화면의 등록·엑셀 일괄 업로드·제외는 관리자 및 해당 구매/수출 운영용역사 조건으로 검사한다. 상세 권한은 CP-01·화면 Description을 따른다.

## 고유코드와 계정

| 대상 | 고유코드 | 로그인 ID | 임시 PW |
| --- | --- | --- | --- |
| 해외바이어 | F + 최초 행사연도 4자리 + 일련번호 4자리 | 발급하지 않음 | 발급하지 않음 |
| 국내바이어 | K + 최초 행사연도 4자리 + 일련번호 4자리 | GK + 행사연도 뒤 2자리 + 일련번호 4자리 | 영문 대문자 1자 + 숫자 6자리 |
| 통역원 | I + 최초 행사연도 4자리 + 일련번호 4자리 | GI + 행사연도 뒤 2자리 + 일련번호 4자리 | 영문 대문자 1자 + 숫자 6자리 |
| 운영용역사 대표·담당자 | 유형별 관리 데이터 | 관리자 지정·담당자 양식의 ID | 발급 기능은 같은 7자리 무작위 규칙 |

- 고유코드는 최초 등록 후 유지하고 연도별 참가이력을 연결한다. 로그인 계정과 혼용하지 않는다.
- 같은 행사 계정은 재조회·재업로드·제외 후 재추가로 재생성하지 않는다. 다른 행사연도는 해당 연도 계정을 사용한다.
- 임시 PW 예시는 A327851이며 정규식은 「^[A-Z][0-9]{6}$」이다. 조회·보기/숨기기로 값을 다시 만들지 않는다.
- 직접 입력하는 관리자·담당자 비밀번호의 영문·숫자 포함 8~20자리 검증과 자동 임시 PW 규칙은 구분한다.

## 기본정보와 계정발송

- 이름+생년월일로 기존 회원을 확인하고 생년월일은 원본 YYYY-MM-DD를 유지한다. 국가·언어·산업군 원본 코드를 임의 대체하지 않는다.
- 기업정보·관심분야 등 엑셀에서 취급하지 않는 추가 정보는 재업로드로 지우지 않는다. 관심분야 제품 카테고리는 산업군과 다른 분류다.
- 해외바이어는 계정 ID/PW·발급/재발급·계정 다운로드를 제공하지 않는다. QR은 행사연도+고유코드로 식별한다.
- BAS-15·COM-07의 선택/일괄 계정발송은 발급 계정과 유효한 연락처가 있는 대상만 처리하는 예시다. 실제 SMS를 전송하지 않는다.
- 상세 입력·연락처 검증·기업정보·행사 배정 중복은 각 현재 화면 Description을 따른다. 예전 날짜별 수정 MD로 항목을 덮어쓰지 않는다.

## 단건 등록

- 행사정보 PRE-01·EVT-01·EVT-02 목록에만 [등록]과 [엑셀 일괄 업로드]를 제공한다. 기본정보 BAS-03·05·07 목록에서는 제공하지 않는다. 등록 모드는 행사정보 PRE-02·EVT-03·EVT-04를 사용하며 BAS-04·06·08과 공통 프로필·폼 모듈을 공유한다.
- 행사정보 등록·엑셀 일괄 업로드는 관리자 및 해당 구매/수출 운영용역사에게 제공한다. 기본정보관리에서는 상세의 기본정보 수정과 행사참가이력·현재 행사 이력 삭제 버튼을 유지한다.
- 이름·생년월일은 등록 시 필수 입력하고, 기존 상세에서는 읽기 전용을 유지한다. 나머지 필드·검증은 상세와 공유한다. 현재 목업은 [중복확인] 시 기존 최신 정보를 제공하고 [저장]으로 전환한다. 저장 Description의 동일 행사 기참가 등록 불가·[등록] 기준과의 차이는 Q11로 관리하며 구현 완료로 간주하지 않는다.
- [목록]은 저장 없이 복귀, [등록] 성공은 진입 목록 복귀와 현재 행사 참가·자동 발급을 처리한다. 해외바이어는 QR만 발급한다. 별도 등록 Description 화면은 생성하지 않는다.
- 검토용 단건 등록 정보는 동일 탭 세션에 보관한다. 운영 DB 등록은 서버 연동 대상이다.

## 행사정보 상세·수정 공용 (2026-11-09)

- 해외바이어 PRE-02, 국내바이어 EVT-03, 통역원 EVT-04는 각각 BAS-04·BAS-06·BAS-08의 공통 수정 폼과 회원 프로필을 사용한다. 관리자 및 해당 상담 운영용역사가 저장할 수 있으며 조회 전용 역할은 기존 조회 화면을 유지한다.
- 이름·생년월일·고유코드와 발급 ID/PW·QR 인증 정보는 변경하지 않는다. 공통 연락처·이메일·필수값·기업정보·관심분야·통역언어 검증을 적용한다.
- 행사정보 PRE-02·EVT-03·EVT-04에서는 행사참가이력을 표시하지 않는다. 기본정보관리 BAS-04·06·08 상세의 참가이력과 현재 행사 삭제는 유지한다. 해외바이어 상세는 기본정보 다음의 숙소정보 및 최하단 방한정보·현황 변경이력을 제공한다.

## 방한·숙소 관리

- SP-02에 따라 미입국 최초 상태와 입국일 기준 일차를 계산한다. 호텔 도착 이후 행사장 동선은 일자별 반복하며 상담 시작·종료는 상담일지 시각으로 기록한다.
- 최신 기록·현재 상태를 맨 위에 표시하고 전체 이력을 내부 스크롤 없이 확인한다. 신규 회원 등록 시에는 방한관리를 하지 않는다.
- PRE-02-p43 수동 등록은 상태·일시·사유를 입력한다. 기존 기록 수정은 일시·사유만 입력하고 상태는 바꾸지 않는다.
- 기록취소는 사유 입력 후 확인창으로 확정하며 취소 이력을 남긴다. 취소·닫기는 미반영한다. 방한 처리 결과는 기본정보 저장 버튼과 무관하게 즉시 반영된다.
- 현황 변경이력 처리자는 실제 작업 계정 이름을 표시한다. 숙소/위치 아래 숙소상세는 선택 입력이며 최대 1,000자다.

## 통역원 인력구분·매칭

- 행사연도별 인력구분은 미지정/일반/예비다. 상세에서 변경할 수 있는 역할은 수출상담 운영용역사이며 관리자는 조회한다.
- 업로드 인력구분은 필수이고 일반/예비만 허용한다. 상세에서 제공하는 미지정 선택과 업로드 입력 허용값을 혼용하지 않는다.
- 1:1 매칭과 변경·취소 사유 및 이력을 유지한다. PRE-04-p44는 변경 전 통역원의 승인 요청 이력이 없는 작성 중 수출일지를 선택 이관하며 최종 매칭과 함께 반영한다.
