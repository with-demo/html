## 사용 종료·호환 주소

- FAQ·자료실과 상담일지 엑셀 일괄 업로드/검증의 사용 종료 페이지는 현행 메뉴에 재등록하지 않는다.
- COM-02~05는 삭제된 화면이다. COM-09는 COM-06으로, BAS-20은 BAS-18 등록 모드로 연결하는 과거 주소다.
- SET-08·SET-09는 그룹 등록·권한 통합 이전 주소이며 새 화면에 ID를 재사용하지 않는다.
- 표준 주소는 「index.html#화면ID」이다. 「pages/*.html」은 기존 주소를 보존하는 이동 파일이다.
- 공지/알림은 NTC-01로 직접 이동한다. 기획정책은 서비스 화면 ID가 없는 별도 페이지이며 새 창으로 열린다.
