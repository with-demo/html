# 화면별 정책

기준일: 2026-11-11 (한국 시간) · 정리본 v1.1

## SP-01 기본정보의 참가이력

화면: BAS-04, BAS-06, BAS-08 · 공통 정책: CP-02, CP-06

기본정보 목록은 해당 행사 참가 상태를 표시한다. 참가이력의 삭제는 현재 선택 행사 행에만 제공하며 해당 행사 미참여·이력 숨김으로 처리한다. 다른 연도의 이력과 원본을 삭제하지 않는다.

상세 명세 관리: 등록·엑셀 일괄 업로드는 행사정보 해외바이어·국내바이어·통역원 목록에서만 제공하며 관리자 및 해당 구매/수출 운영용역사가 사용할 수 있다. 기본정보관리에서는 상세 기본정보 수정과 참가이력 조회·현재 행사 이력 삭제를 유지한다. 이름·생년월일 중복확인 시 기존 최신 정보를 불러오고 저장하면 기존 회원을 업데이트한다.
근거: S07, S08

## SP-02 해외바이어의 계정 예외

화면: PRE-01, PRE-02 · 공통 정책: CP-02, CP-03, CP-04

해외바이어는 로그인 ID/PW를 발급하지 않는다. 단건 등록·업로드 반영 즉시 행사 참가 목록에 표시하고 행사연도와 고유코드로 QR을 발급한다. 제외 시 QR 미사용, 같은 행사 재추가 시 기존 QR을 다시 사용한다.

상세 명세 관리: 방한기록이 없는 최초 상태는 미입국이다. 입국→호텔 이동→호텔 도착 이후 전시장 출발→전시장 입장→통역원 만남→상담 시작·종료→행사장 퇴장을 일자별 반복 기록한다. 상담 시작·종료는 QR 스캔이 아니라 상담일지 시각과 연동한다. 입국일을 1일차로 한국 날짜 차이를 계산하며 입국 전 기록·입국일 미등록을 구분한다. 최신 기록일시 내림차순으로 표시하고 최신 유효 기록을 현재 상태로 삼는다. 방한정보는 상세 최하단에서 내부 스크롤 없이 표시하며 수동 등록·수정·취소는 기본정보 저장과 별도로 즉시 반영한다. 기존 기록 수정은 일시·사유만 허용하고 상태는 변경하지 않는다. 사유 입력 후 기록취소 확인창을 제공하고 변경이력을 남긴다. 처리자는 실제 계정 이름이다. 숙소/위치 아래 숙소상세 textarea를 제공한다. 신규 회원 등록 모드에서는 방한관리를 제공하지 않는다.
근거: S04, S05, S15

## SP-03 국내바이어·통역원의 발급 기준

화면: EVT-01, EVT-02 · 공통 정책: CP-01, CP-03, CP-04

국내바이어·통역원은 단건 등록·업로드 반영 즉시 해당 행사 ID/PW와 QR을 자동 발급한다. 제외하면 행사 목록에서 숨기고 발급 ID·QR을 미사용 처리한다. 동일 행사 재추가 시 기존 ID/PW와 QR을 그대로 재활성화한다.

상세 명세 관리: 기존 GK/GI 발급 규칙·7자리 임시 PW를 유지한다. 발급 규칙과 재사용 기준은 회원_행사_계정.md에서 관리한다. 국내바이어·통역원 상세는 BAS-06·BAS-08과 같은 수정 폼·검증·회원 프로필을 공유한다. 관리자·해당 용역사는 기본정보를 저장할 수 있다. 행사정보 상세에서는 행사참가이력을 표시하지 않으며 기본정보관리 상세에서 참가이력을 관리한다. 통역원 인력구분은 행사연도별 미지정/일반/예비이며 수출상담 운영용역사만 변경한다. 통역원 업로드 양식은 인력구분 필수, 일반/예비만 허용한다.
근거: S04, S05

## SP-04 매칭 변경·취소의 이력

화면: PRE-04, PRE-04-p32, PRE-04-p44 · 공통 정책: CP-01, CP-06, CP-07

기존 매칭의 변경·취소에는 사유가 필요하며 배정이력을 보존한다. 바이어·통역원은 1:1로 매칭하며 현재 담당자를 포함해 이미 매칭된 통역원은 후보에서 제외한다.

상세 명세 관리: 후보의 일반·예비 인력구분과 건수 검색·긴급 체크·버튼별 확인창은 매칭관리 명세에서 관리한다. 통역원 변경 시 PRE-04-p44에서 해당 행사·바이어·이전 작성자의 수출상담일지 중 승인 요청 이력이 없는 작성 중 일지만 표시하고 선택 이관하며, 최종 통역원 매칭에서 이관·배정을 함께 반영한다. 새 통역원의 미매칭 여부를 다시 검사하며 기존 연결을 자동 해제하지 않는다. 취소·닫기는 미반영하고 저장 실패 시 원래 배정·작성자를 유지한다.
근거: S14

## SP-05 수출상담일지의 역할별 등록 상태

화면: JNL-05, JNL-14, JNL-16 · 공통 정책: CP-01, CP-05

현재 수출 흐름에서 통역원의 신규 등록은 승인 요청으로, 관리자·수출 용역사의 신규 등록은 승인 완료로 저장된다. 일괄 검수는 승인 요청 상태를 대상으로 한다.

상세 명세 관리: 현재 구매 화면은 상담수준·주요 보완사항·후속조치와 250자 이상·반복 입력 검증을 제공하고 구매 만원 입력/KRW 저장, 수출 신규 USD 기본값과 USD/KRW 선택을 제공한다. 수출 화면은 기존 상담결과·상담제품·상담상세 구성을 사용한다. standard-journal.js는 현재 진입에 연결돼 반복 입력 검사에 사용되지만 표준 모듈 전체 폼·정규화와 동일하게 통합된 것으로 간주하지 않는다. 유형별 실제 필드·상태·검증은 저장 Description과 현재 폼을 따른다. 상세 검토는 Q10으로 관리한다.
근거: S11, S12, S13

## SP-06 QR 업무별 대상 분리

화면: PRE-03, PRE-12, JNL-03 · 공통 정책: CP-01, CP-04

방한·출결 QR은 관리자·구매/수출 용역사 흐름이며, 상담 시작 QR은 국내바이어·통역원 흐름이다. 상담 시작에서는 참가기업을 식별한다.

상세 명세 관리: 카메라 UI·권한 오류 안내·상태별 체크 동작은 QR 화면 명세를 참조한다.
근거: S15, S16

## SP-07 공지/알림의 단일 진입과 열람 범위

화면: NTC-01, NTC-04, NTC-15 · 공통 정책: CP-01

공지/알림 대메뉴는 NTC-01 목록으로 바로 이동한다. FAQ·자료실은 사용 종료이며 별도 메뉴·페이지 정책으로 다시 추가하지 않는다. 관리자는 작성·수정하고 일반 사용자는 본인 대상과 전체 대상 공지를 열람한다. 연도 전체 공지는 모든 연도에 적용한다. 진행·종료 행사 연도를 선택하며 대기 행사는 제외한다.

상세 명세 관리: 등록·수정은 NTC-15 공용 편집 화면을 사용하고 기존 NTC-16은 수정 모드로 연결한다. 공지구분은 사용하지 않는다. 검색은 연도 셀렉트·대상 라디오로 적용한다. 제목·대상·첨부파일·알럿/컨펌 상세는 공지/알림 화면에서 관리한다.
근거: S01, S17

## SP-08 만족도 조사 개방과 응답 보존

화면: NTC-08 · 공통 정책: CP-02, CP-07

국내바이어·통역원의 만족도 조사 메뉴는 행사 마지막 날부터 표시한다. 해당 연도·대상 유형의 사용 설문과 원본 준비 여부를 확인하고, 직접 URL 접근도 같은 조건으로 제한한다. 통역원은 본인 및 담당 해외바이어별로 응답한다. 대상 탭 전환은 초안을 유지하고 다른 페이지 이동·새로고침은 미제출 초안을 초기화한다.

상세 명세 관리: 단일응답형·척도형은 보기별 다음 문항 이동을 지정할 수 있으며 미지정 보기는 기본 순서로 진행한다. 현재 등록 화면은 과거 표시 조건 대신 이 문항 이동 설정을 사용한다. 설문 ID·행사연도·응답자 고유코드의 1회 제출 기준과 국내바이어 반복 시연 예외를 구분한다. 응답이 있는 설문은 수정 대신 복사하여 등록한다.
근거: S18, S19

## SP-09 운영용역사·담당자 관리 범위

화면: BAS-15, BAS-17, BAS-19, COM-07, COM-08 · 공통 정책: CP-01, CP-02, CP-07

운영용역사는 행사 배정과 기업·대표담당자 정보를 관리하며, 용역사 담당자관리는 로그인한 회사·행사 범위로 제한한다. ID 중복과 행사연도·구분 중복을 각각 검사한다. 계정발송은 유효한 발급 정보와 연락처가 있는 대상만 처리하는 목업 예시다.

상세 명세 관리: 등록·상세의 입력 항목, ID 수정 가능 여부, 비밀번호 검증과 선택·일괄 발송은 각 화면 Description을 따른다. 실제 SMS·인증 서버는 미연동이다.
근거: S08, S13

## SP-10 공통 헤더와 내정보 진입

화면: COM-06 · 공통 정책: CP-01

헤더에는 이름님과 역할 배지를 표시하고 COM-06으로 이동한다. 관리자·구매/수출상담 운영용역사는 상단 알림 메뉴를 표시하지 않는다. 국내바이어·통역원은 기존 알림 메뉴를 유지한다. 모바일에도 같은 역할별 노출 조건을 적용한다. 사이드바 로고 아래·하단 역할 표시는 사용하지 않는다.

상세 명세 관리: 유형별 본인 정보는 원천 기본정보의 입력·검증 정책을 따르고 이력 영역은 내정보에 표시하지 않는다. COM-09는 과거 주소 호환용이며 별도 팝업 정책으로 관리하지 않는다.
근거: S08, S16

## SP-11 출결 대시보드의 공통 집계와 보기 전환

화면: MON-08 · 공통 정책: CP-01, CP-07

전체 출석률·참석 예정·출석·미출석 요약은 리스트형·그리드형 탭 위에 공통 표시한다. 관리자: 국내·해외바이어·통역원, 구매용역사: 국내바이어, 수출용역사: 해외바이어·통역원을 조회한다.

상세 명세 관리: 리스트형은 출석자만 최신순 표와 유형별 내부 스크롤로 표시한다. 그리드형은 참석 예정자 전체를 출석/미출석 카드로 표시하고 전체/출석/미출석 필터·자동/3/4/5/6개 카드 수를 제공한다. 보기 전환 시 검색을 유지하고 집계는 검색·필터와 분리한다. 관리자 유형별 영역은 데스크톱 3열, 좁은 화면은 세로 배치한다. 보기·카드 수 설정은 현재 브라우저에 저장한다. 현행 자동 갱신은 예시 출결 데이터이며 실제 QR·서버 출결 미연동이다. 2번 Description은 리스트형·그리드형·공통 기준을 나누어 설명한다.
근거: S21
