# BAS-17 담당자 목록 엑셀 다운로드

- 담당자 목록 위에 엑셀 다운로드 버튼을 제공한다. 관리자만 사용한다.
- 현재 용역사·행사에 배정된 담당자 중 검색 조건에 맞는 하위 담당자를 모두 포함한다. 대표담당자는 화면과 동일하게 첫 행에 항상 포함한다.
- 항목: 이름·소속·연락처·이메일·아이디·비밀번호·사용여부. COM-07과 동일한 공통 변환 함수를 사용한다.
- 비밀번호는 보기/숨기기 상태와 관계없이 현재 발급값을 포함한다.
- 파일명: G-FAIR_행사연도_용역사 담당자_YYYYMMDD.xlsx (다운로드일은 한국 시간 기준). 다운로드 완료: 현재 검색 결과를 엑셀로 다운로드했습니다.
- 실패: 엑셀 생성에 실패했습니다. 다시 시도해 주세요.
- 완료·실패 시 상세 화면과 검색 조건을 유지한다.
