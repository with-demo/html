# 그룹권한 및 설문 예시 반영

2026-10-28 (한국 시간), with

- 권한 기준: 사용자가 공유한 사이트맵 시트의 사용자별 메뉴노출 및 권한. O·△는 체크, X는 해제하며 △의 기존 담당범위 제한은 유지한다.
- 메뉴 접근 권한은 현재 메뉴 트리 단위로 관리한다. 상세·등록·팝업별 개별 기능 권한으로 확장하지 않는다.
- 그룹 등록·상세는 그룹명·사용여부만 편집한다. 신규 그룹은 메뉴 미선택으로 생성한다.
- 목록의 메뉴권한 팝업은 기본정보 없이 메뉴 선택만 편집한다. 기존 팝업 유형 번호 SET-01-p13을 유지한다.
- 목업 내 그룹 설정이며 실제 서버 인증·인가 정책을 변경하지 않는다.

## 원본 설문 구성 가능 여부

- 국내 바이어 구매상담회 HWP v3: 문1~문12 및 응답자 인적 사항을 13개 그룹·32개 세부 문항으로 구성.
- 해외 바이어 수출상담회 HWP v3: Q1~Q9 및 Respondent information을 10개 그룹·29개 세부 문항으로 구성. 질문·보기는 영문 유지.
- 표 형태 만족도는 그룹 안의 개별 척도형 문항으로 구성하므로 기존 등록기의 5개 문항 유형으로 표현할 수 있다.
- 국내 최대 2개 선택 문항 3개를 위해 복수응답의 최대 선택 개수 설정을 추가했다. 0은 제한 없음이다.
- 고객유형별 기업유형 및 실제 구매 여부 후속 질문은 앞선 문항의 보기를 선택하는 표시 조건으로 설정한다. 이전 선택형 문항만 연결해 순환 조건을 방지한다.
- 미리보기는 입력·제출 없이 모든 문항과 표시 조건·선택 개수를 검토한다. 실제 참여 화면의 응답 검증 연동은 별도 구현 범위다.
- 원문의 해외 Q5 `3) (To be determined)`는 임의 확정하지 않고 검토 필요 문항으로 유지했다. 해외 문구·원문 오탈자는 임의 번역·교정하지 않았다.
- 네트워킹 리셉션은 원문의 If applicable에 따라 선택 응답으로 두었다. 주관식 인적 사항·제안사항과 미확정 문항도 선택 응답이다. 나머지 문항은 검토용 필수 설정이며 등록기에서 변경할 수 있다.
- 조사기간 2026-10-01~2026-12-31, 예상 소요시간 10분은 예시 설정이며 원문 확정값이 아니다. 실제 운영 전 확인한다.
- 예시는 위 2건만 제공하며 응답은 만들지 않는다. 기존 데모 6건 저장소와 분리한 새 목업 저장 키를 사용한다.
