# 회원관리 참여여부·계정발급 변경 (2026-10-30 한국 시간)

- 기본정보관리는 회원 기본정보·현재 행사 참여여부·참가이력 관리
- 참여여부는 회원·행사연도별로 분리하며 새 행사연도에는 전년도 참가를 승계하지 않고 미참여로 시작
- 정상 업로드한 모든 회원은 진행 행사연도에 신규/참가로 반영, 업로드에 없는 기존 회원은 변경하지 않음
- 미참여 처리는 현재 행사만 제외하며 회원 기본정보·고유코드·과거 참가이력 보존
- 국내바이어·통역원 계정은 행사정보에서 담당 용역사가 명시적으로 발급, 기본정보 조회·업로드로 자동 발급하지 않음
- 해외바이어는 계정 없이 행사연도+고유코드 QR만 사용

## 미참여 처리

- 선택한 회원을 현재 행사연도에만 미참여로 처리
- 미참여 처리 확인창에서 [미참여 처리]를 누르면 반영, [취소]·X·Esc는 변경 없이 닫기
- 기본정보관리 목록에는 회색 미참여로 유지하고 행사정보 목록에서는 제외
- 회원 기본정보·고유코드·발급 계정·과거 참가이력은 삭제하지 않음
- 바이어는 다시 업로드하면 해당 행사 참가로 복원. 통역원은 기존 상세 참여여부 변경도 유지

## 권한과 확인창

- 국내바이어: 구매상담 운영용역사 / 통역원: 수출상담 운영용역사에서 계정발급. 관리자는 발급하지 않음.
- 미참여 처리는 기본정보관리의 관리자, 행사정보의 관리자·해당 용역사가 실행.
- 미참여·계정발급은 선택 대상과 행사연도 확인 후 진행, 취소·X·Esc는 변경 없음.
