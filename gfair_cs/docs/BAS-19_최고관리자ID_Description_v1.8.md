# BAS-19 · v1.8 · 2026-10-26

- 운영용역사 최고관리자용 계정 ID를 필수 입력
- 중복확인 시 앞뒤 공백을 제거하고 관리자·대표담당자·하위 담당자의 기존 ID와 비교
- 빈 ID 또는 중복 ID는 확인 실패, 사용 가능한 ID만 확인 완료
- 확인 후 ID를 변경하면 확인 결과 초기화 및 재확인 필요
- 등록 시 ID 중복 여부와 확인 완료 값을 다시 검증
- 비밀번호 입력란은 제공하지 않고 등록 시 비밀번호 자동 생성
- 등록한 ID와 자동 생성 비밀번호는 BAS-17 대표담당자 발급ID·PW에 연결
- 목업은 현재 탭 예시 데이터에만 반영하며 실제 서버 계정은 생성하지 않음
