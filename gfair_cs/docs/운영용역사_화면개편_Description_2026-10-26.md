## BAS-15 filter-draft-20261022-bas-15-keyword

- detail: - 연도·구분 조건과 AND 조건으로 결합
  - 빈 값 또는 공백만 입력하면 키워드 조건 해제

  - 키워드 입력 후 Enter는 검색 버튼과 동일하게 처리
  - 초기화 시 연도·구분·검색 범위를 전체로 변경하고 키워드를 비운 뒤 전체 목록 조회

## BAS-15 운영용역사 목록

- 연도·구분·기업·담당자 이름·사용여부·하위 담당자수 순서로 표시
- 기업명에만 밑줄 링크를 표시하고 클릭 또는 Enter로 BAS-17 이동
- 기업명 외 셀과 행 전체는 상세 이동 대상에서 제외
- 선택한 행의 행사연도·구분·기업을 상세에 전달
- 하위 담당자수는 해당 기업·행사연도의 하위 담당자 수이며 대표담당자는 제외

- 연결: `#content .operator-list table`

## BAS-17 기본정보

- 목록에서 선택한 행사연도·구분의 운영용역사 기본정보 조회
- 행사연도·구분·기업명·사용여부 네 항목 표시
- 담당자 정보와 별도 영역으로 나누어 노출

- 연결: `#content .operator-basic`

## BAS-17 담당자 키워드 검색

- 검색 범위 셀렉트 없이 키워드 입력란과 검색·초기화 버튼 제공
- 하위 담당자의 이름·연락처·이메일·발급ID를 대소문자 구분 없이 포함 검색
- 검색 버튼 또는 Enter로 적용하고 초기화 시 키워드 해제
- 대표담당자는 검색 결과와 관계없이 첫 행에 고정 노출
- 일치하는 하위 담당자가 없으면 검색 조건에 맞는 하위 담당자가 없습니다. 안내

- 연결: `#content [data-management-form="operator-staff-search"]`

## BAS-17 대표·하위 담당자 정보

- 이름·연락처·이메일·발급ID·PW 순서로 표시
- 첫 행은 목록의 담당자와 동일한 대표담당자이며 이름 앞에 [대표담당자] 라벨 표시
- 하위 담당자는 선택한 기업·행사연도에 소속된 담당자만 조회
- 대표 계정은 선택한 행사연도·구분의 발급ID·PW 표시
- 연락처·이메일이 없으면 미등록, 발급ID가 없으면 미발급, PW가 없으면 — 표시

- 연결: `#content .operator-staff table`

## BAS-17 PW 보기·숨기기

- 발급된 PW는 기본 마스킹
- 행별 보기 버튼으로 해당 담당자의 PW를 표시하며 숨기기로 다시 마스킹
- 미발급 계정은 PW와 보기 버튼을 제공하지 않음
- 상세 이동 시 이전에 표시한 PW를 다시 마스킹

- 연결: `#content .operator-staff table tbody`

## BAS-19 [목록], [등록] 버튼

- 영역 제목은 운영용역사 기본정보로 표시
- 하단 우측에 목록·등록 순서로 버튼 한 쌍만 표시
- 목록 선택 시 별도 확인 없이 BAS-15 이동
- 등록 시 기존 필수값·이메일 형식·중복 기업 검증을 유지
- 정상 등록 시 목록에 반영하고 BAS-15 이동
- 입력 오류가 있으면 등록을 중단하고 입력 화면 유지

- 연결: `#content .page-bottom-actions`
