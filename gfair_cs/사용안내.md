# G-FAIR KOREA 목업 사용안내

기준일: 2026-11-11 (한국 시간)

- 공개 주소: https://with-demo.github.io/html/gfair_cs/index.html
- 화면 표준 주소는 「index.html#화면ID」이다. 개별 pages HTML은 기존 주소를 보존하는 이동 파일이다.
- 상단 화면 선택·사용구분·Description·기획비고는 검토 도구다. [기획정책]은 새 창의 별도 정책 문서로 열린다.
- 현행 문서의 시작점은 [docs/README.md](docs/README.md)다. 예전 날짜별 초안이나 outputs를 현행 정책 대신 사용하지 않는다.
- 서비스 화면은 예시 데이터 목업이다. 실제 운영 인증·DB·SMS·외부 API와 별개이며, Description·댓글은 공동작업 서버에서 관리한다.
- 로컬 파일은 화면 미리보기에 사용할 수 있으나 Description·공동작업에는 인터넷과 허용된 사이트 출처가 필요하다.
- 공통 도구는 common/, 프로젝트 화면은 gfair_cs/에서 관리한다. 국가·언어·산업군과 등록 XLSX는 사용자 원본을 유지한다.
- 정책·MD·구글시트에 자동 양방향 연동은 없다. 변경할 때 같은 정책 ID와 실제 배포 상태를 함께 확인한다.
